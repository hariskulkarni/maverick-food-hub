Demo Accounts

Comprehensive access guide for every role, restaurant, and feature in the seeded non-production environment.

To populate these on a fresh database, run the following from apps/web:

npm run db:seed:cuisines        # 7 restaurants, menus, orders, staff, riders, customers
npm run db:seed:rider-features  # super-admin, rider avatars, KYC docs, live pool

Note: seed-rider-features.ts prints this same directory to the console when it finishes.

Rider Native Android app (Oak & Sizzler Rider) Phone + OTP

OTP Bypass (Dev Mode)

The VPS runs with OTP_DEBUG_LOG=true. After clicking "Send code", the OTP is returned in the API response and logged: pm2 logs rm-web shows OTP issued (dev) … code=######.

Riders enter the 10-digit number (the app prepends +91). Example: for +919875294185, type 9875294185.

Notes
