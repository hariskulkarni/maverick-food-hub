## What it is

A happy hour rule changes item prices automatically during the times you choose – no code needed. Find it under **Storefront CMS > Promotions > Happy Hours**. The page shows **Active**, **Upcoming** and **Expired** counts and **Savings this week** (passed to customers since Monday).

## Create a rule

1. Tap **New rule**, or **Start with Weekday Happy Hour** if you have none yet.
2. Enter a **Rule name**, an optional **Description** and a **Priority (higher wins)**.
3. Choose the scope: **All restaurant**, **Category**, **Menu item** or **Combo**, and pick the category, item or combo if needed.
4. Choose the discount: **Percentage** (enter **Percent off (%)**), **Fixed price** (enter a **New unit price (₹)**, for example every cocktail at ₹199) or **Amount off** (enter **Amount off (₹)**).
5. Optionally set a **Minimum price floor (₹)** so prices never drop below it.
6. Add schedule windows per day, or use a preset: Weekday Happy Hour (Mon–Fri 17:00–20:00), Weekend Lunch (Sat and Sun 12:00–15:00) or Always-on.
7. Set **Valid from** (required) and optionally **Valid until**, check the preview, and tap **Create rule**.

## How prices are worked out

- When several rules match an item, the highest priority wins, then the bigger saving, then the more specific scope (item before category before whole restaurant).
- Item-scope rules do not apply to combos.
- Offers apply after happy-hour prices. For example, a 50% happy hour plus a 10% offer means the customer pays 45% of the original price on those items.

## Good to know

- **A rule with no schedule windows runs 24/7** within its validity dates. The editor warns you when this is the case.
- Each window must end after it starts.
- Use the tabs to see Active, Upcoming, Expired or All rules, and filter by scope.
- **Deactivate** stops a rule immediately; past orders are unaffected.
