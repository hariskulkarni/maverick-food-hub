## What it is

A coupon campaign is a promo code meant to move customers between channels. Find it under **Storefront CMS > Promotions > Coupon Campaigns**. There are two channels:

- **Dine-in → Online** – for example, print a code on dine-in receipts that guests use on your online storefront.
- **Online → Dine-in** – a code issued to online customers, redeemable in the restaurant.

## Create a campaign

1. Tap **New campaign**.
2. Enter an **Internal name** and a **Code prefix** (capital letters and numbers only, at least 2 characters), plus a **Customer-facing description**.
3. Pick the **Channel** and the discount type. Both are locked after creation.
4. Set the discount (**Percent off (%)** with **Max discount (₹)**, or **Flat off (₹)**), **Min order (₹)**, **Per-user limit**, **Total uses**, **Valid from** and **Expires at**.
5. Enter **How many receipts / emails will you print or send?** – this is used to calculate the conversion rate.
6. Choose **Active**, **Paused** or **Draft** and save.

For a flat discount the customer code is your prefix. For a percentage discount, four random digits are added to the prefix. The code is shown on the campaign card.

## Print the QR poster

Tap **View QR** on a campaign, then **Print poster**. The poster shows the discount, the code and a QR code that opens your storefront with the code already filled in.

## Track results

The campaigns page shows **Active campaigns**, **Redemptions this month**, **Revenue this month** and **Avg conversion**. Tap **Reports** on a campaign for **Issued**, **Distributed**, **Redeemed**, **Conversion**, **Revenue**, **Discount cost** and **Net ROI** over 7, 30 or 90 days, plus the latest 50 redemptions.

## Good to know

- Each campaign creates a matching offer, which is what checkout checks. See [Offers](help:restaurant-offers).
- Filter the list by **All**, **Active**, **Paused** or **Expired**, and by channel.
- Update the distributed count after each print or email run so conversion stays accurate.
