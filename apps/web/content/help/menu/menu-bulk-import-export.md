## What it is

The **Bulk import & export** panel at the top of **Storefront CMS > Menu** lets you load many items at once from a spreadsheet, or download your menu.

## Download a file

- **Blank template** – an empty sheet with the right columns.
- **Indian catalog template** – a template pre-filled with sample dishes.
- **Export current menu** – your current menu in the same format.

The template columns are **Category**, **Item Name**, **Description**, **Price**, **Veg**, **Spicy Level**, **Prep Time (min)** and **Available**. A "How to use" sheet inside the template explains them.

## Fill in the sheet

- One row per item. **Category**, **Item Name** and **Price** are required.
- **Veg**: "Veg" or "Non-Veg". **Available**: "Yes" or "No".
- **Spicy Level**: 0 (none) to 3 (very spicy).
- Categories that don't exist yet are created automatically.
- The header row must be within the first 5 rows of the sheet.

## Import

1. Choose your **.csv** or **.xlsx** file and tap **Preview import**.
2. Check the preview table. Each row is marked **New**, **Update** or **Error**, with notes.
3. If there are errors, fix them in your file and preview again – you cannot apply while error rows remain.
4. Tap **Confirm & apply**. The button shows how many rows will be created or updated.

## Good to know

- Re-importing updates existing items. An item is matched by its category and item name (not case-sensitive).
- Import does not add photos, sizes/variants or add-ons. Add those in the item editor afterwards. See [Sizes, variants and add-ons](help:menu-variants-add-ons).
- Import works on your restaurant's first active branch. If you have no active branch, the panel tells you to add one.
