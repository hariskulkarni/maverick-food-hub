## What's required

At the **Hand over** step, you must enter the customer's **delivery code** before the order can be marked delivered. A photo is optional.

## Enter the delivery code

1. Tap **I've reached the customer**. The **Confirm hand-over** section appears.
2. Ask the customer for their delivery code and type it in the box.
3. Tap **Confirm delivery**.

The code is digits only, and you need to enter at least 4 digits. If you accidentally paste spaces or other characters, the app removes them.

### If the code is rejected

- **"Enter the 4-digit code the customer gives you."** or **"Enter at least 4 digits."**: the code is too short.
- **"That code is incorrect. Ask the customer to read it again."**: the digits don't match. Check them with the customer and try again.
- **"No delivery code is set for this order. Contact support."**: the order can't be confirmed with a code. Contact support from **Help & Support**.

## Add a proof-of-delivery photo (optional)

1. In the hand-over section, tap **Add proof-of-delivery photo**.
2. Allow camera access if your phone asks, then take the photo.
3. Once it uploads, the button reads **Proof photo attached — retake**. Tap it again to replace the photo.

The photo is saved with the delivery. It isn't required to confirm the delivery.

## After confirming

You'll see **Delivered!**. The delivery's earnings are added to your lifetime earnings, and any incentive target you just reached is credited. See [Understand your Earnings tab](help:rider-earnings-screen).

## Good to know

On cash orders, collect the payment before you confirm. You can take cash, or let the customer pay by UPI or card. See [Collect cash on delivery](help:rider-cash-on-delivery).
